# Shahih Bukhari Plus - Portal Digital Hadits Terlengkap

**created by. Digitab Team**

Portal digital ensiklopedia lengkap Kitab Shahih Al-Bukhari dengan **7.563 hadits utuh**, silsilah sanad lengkap hingga Rasulullah ﷺ, terjemahan Bahasa Indonesia & English, serta integrasi **Syarah Fathul Baari (36 Jilid)** naskah Maktabah Syamilah langsung di setiap nomor hadits.

---

## 🌟 Fitur Utama & Keunggulan

1. **Desain UI/UX Modern Islami Sesuai Standar Web App**
   - Panel Samping Kiri dengan Navigasi 10 Menu Lengkap & Kartu Keanggotaan Premium.
   - Bilah Pencarian Cepat (*Pill Search*) terintegrasi pencarian nomor hadits, tema, dan kata kunci.
   - Banner Utama Artistik 16:9 dengan Tombol Interaktif 3D (*Mulai Baca*, *Download Offline/PDF*).
   - 8 Kartu Navigasi Cepat Warna Pastel (*Semua Kitab, Indeks Tematik, Pencarian, Syarah 36 Jilid, Biografi Perawi, Hadits Pilihan, Bookmark, Catatan Saya*).
   - *Slider* 6 Kitab Pilihan (*Iman, Ilmu, Wudhu, Shalat, Zakat, Puasa*).
   - Panel Kanan Mutiara Hadits Hari Ini, Statistik Koleksi (7.563 Hadits, 97 Kitab, 36 Jilid), Progres Membaca Terakhir, dan Riwayat Baca.

2. **Sistem Autentikasi & Akun Pengguna**
   - Masuk (Login) dan Daftar Akun Baru (Register) dengan Username & Password.
   - Profil Pengguna (Default Demo: **Agus Gunawan, M.Pd.** dengan status `👑 Premium`).
   - Sesi tersimpan aman di peramban pengguna.

3. **Fitur Aplikasi Berbayar (SaaS Freemium / Premium)**
   - Modal Upgrade dengan 3 Pilihan Paket:
     - Bulanan (Rp 29.000 / bulan)
     - Tahunan (Rp 199.000 / tahun)
     - Seumur Hidup / Lifetime Pro (Rp 499.000 - Sekali Bayar)
   - Simulasi Pembayaran Lengkap: QRIS Otomatis, Transfer Virtual Account Bank, dan Kode Voucher Aktivasi.

4. **Modul Kajian & Studi Hadits Lengkap**
   - **Indeks Tematik**: Klasifikasi hadits per tema (Akidah, Thaharah, Shalat, Zakat, Haji, Muamalah, Akhlak, Sirah, Fitnah Akhir Zaman).
   - **Hadits Pilihan**: 40 Hadits Mutiara Kaidah Emas Kehidupan lengkap dengan syarah ringkas.
   - **Catatan Saya**: Fitur penulisan faedah ilmiah per nomor hadits.
   - **Riwayat Baca**: Riwayat penjelajahan otomatis.
   - **Bookmark**: Penanda hadits favorit.

5. **Akses Offline & Tanpa Kuota**
   - Dukungan Progressive Web App (PWA) untuk Android.
   - Paket Desktop Windows Mandiri (.bat otomatis dengan server Python/Node lokal).

## 🚀 Cara Menjalankan Secara Lokal

```bash
# 1. Pasang dependensi
npm install

# 2. Jalankan server pengembangan
npm run dev

# 3. Bangun versi produksi
npm run build
```
